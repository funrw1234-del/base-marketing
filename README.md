# Base Marketing — база знаний

Структурированная база материалов по прокачке себя, маркетингу и продажам, собранная командой специалистов. Материалы поступают порциями и раскладываются по разделам ниже.

## Структура

- **01-self-development/** — прокачка себя: мышление, состояние, работа с тревожностью, визуализация, привычки.
- **02-marketing/** — стратегия, позиционирование, трафик, контент, воронки.
- **03-sales/** — скрипты, работа с возражениями, переговоры, CRM.
- **04-tools-and-templates/** — чек-листы, шаблоны, таблицы, промпты.
- **05-cases/** — разборы кейсов и примеры.
- **_inbox/** — сырые материалы, ещё не разобранные по разделам.
